# Design System — Jiawei Wang Portfolio

## Atmosphere
Gallery-airy editorial portfolio with a technical spine. Warm, quiet, precise, and slightly tactile. No SaaS-dashboard language. The 3D character is the hero visual, not a decorative card.

## Design dials
- Creativity: 8/10
- Density: 4/10
- Variance: 8/10
- Motion: 6/10

## Palette
- Bone canvas: #F4F1E9
- Ink: #151513
- Muted ink: #6D6961
- Burnt vermilion accent: #D65F3D
- Warm white: #FFFDF8
- Structural lines: rgba(21,21,19,.16)

Use one accent only. No purple-blue gradients. No neon. No glassmorphism as a default surface.

## Type
- Display: Iowan Old Style / Palatino / Georgia fallback. High contrast, large editorial scale.
- UI/body: native system sans for clarity and load reliability.
- Metadata: system mono, uppercase, tracked.

## Layout
12-column editorial grid. Asymmetry is intentional. Sections must not all reuse the same card grid. Prefer rules, rows, sticky side notes, oversized type, and negative space.

## Motion
One coherent entrance system, pointer-driven 3D parallax, restrained hover transitions, no bouncing widgets. Respect prefers-reduced-motion.

## Anti-patterns
No nested cards. No rounded-square icon tiles. No hero metrics card grid. No gradient text. No arbitrary pills. No repeated 2x2 card sections. No giant blur blobs behind every section. No decorative arrows or plus signs.
